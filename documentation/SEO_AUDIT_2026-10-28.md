# SEO audit — volux.devlifeeasy.com (2026-10-28)

Scope: the static site in `docs/` (6 locale home pages, privacy/terms/refund, 404,
`robots.txt`, `sitemap.xml`, `llms.txt`), checked from source with a script
(title/description length, canonical, hreflang, Open Graph, JSON-LD parse, headings,
image alt) and by hand. No live crawl, no Search Console or analytics data, no
PageSpeed run — so rankings, indexing status and Core Web Vitals are **unverified**.
This file lives in `documentation/` because `docs/` is the published site root.

## What is already in good shape

- One `<h1>`, correct `lang`, self-referencing canonical on every real page.
- Home pages in six locales with a full 6-language + `x-default` hreflang set, and
  the same set is in the sitemap.
- Open Graph and Twitter tags on every page; JSON-LD (`SoftwareApplication`,
  `WebApplication`, `FAQPage`) parses on all six locales.
- All `<img>` have descriptive alt, width/height and lazy loading.
- Affiliate links carry `rel="sponsored"`; 404 is `noindex`.

## Findings (most important first)

1. **Self-awarded rating in structured data (risk).** Every locale's JSON-LD has
   `aggregateRating` 5.0 from `ratingCount: 1`. One rating is not a meaningful
   aggregate, and ratings Google cannot tie to reviews shown on the page violate
   its structured-data policy (possible manual action that removes rich results).
   Remove it until there is a real count that the page also displays.
2. **Social/preview and sitemap images hosted on `raw.githubusercontent.com`.**
   `og:image` and all `image:loc` entries point at the `main` branch of the repo:
   slow, rate-limited, not served from the site's own domain, and they break if a
   file is moved or the repo goes private. The OG image is 1280×800 (1.6:1); the
   usual 1200×630 (1.91:1) crops less. Copy the images into `docs/assets/` and
   reference `https://volux.devlifeeasy.com/assets/…`.
3. **Titles and descriptions too long to display.** Titles: en 71, vi 82, pt 76
   characters (Google shows roughly 60). Descriptions: es 198 and pt 189 characters
   (roughly 155–160 shown); zh 102 / ja 107 are fine for CJK. Source of truth is
   `docs/_i18n/*.json`; fix there and run `make i18n`.
4. **`sitemap.xml` is hand-maintained and stale.** Six pages say `lastmod`
   2026-05-26, the legal pages 2026-04-19, but the locale pages were last changed
   2026-06-17 (git). `tools/build-i18n.mjs` does not generate the sitemap. A wrong
   `lastmod` teaches Google to ignore the field; generate it from file mtimes in
   the build. `changefreq`/`priority` are ignored by Google and can be dropped.
5. **`_template.html` is a public file with placeholder markup.** It carries
   `canonical="{{canonical_url}}"` and `index, follow`. `robots.txt` disallows it,
   but robots only stops crawling — a linked URL can still be indexed, and a
   disallowed page's `noindex` is never seen. Confirm the host really excludes
   underscore paths (Jekyll does by default; no `.nojekyll` was checked) or move
   the template and `_i18n/` out of `docs/`.
6. **Third-party promo block on the product home page.** A "partners" section
   (Binance referral, Shopee, TikTok) sits on the homepage of a volume
   extension. Links are correctly `sponsored`, but unrelated commercial content
   dilutes topical focus and can look like a doorway to quality raters. Consider
   moving it off the homepage. This is a product decision, not a defect.
7. **Render-blocking Google Fonts** (Fraunces, IBM Plex ×2) with only
   `preconnect`. Self-hosting or reducing weights helps LCP; measure first.
8. **Minor:** legal pages are English-only and correctly have no alternates;
   `robots.txt` names `Claude-Web`/`Anthropic-AI` user agents that are no longer
   the crawlers' current names — harmless because `User-agent: *` already allows
   all; `llms.txt` is present and in sync with the feature list as of its last edit.

## Suggested order

1. Remove `aggregateRating` from the six locale JSON-LD blocks (item 1).
2. Move OG/sitemap images onto the site domain (item 2).
3. Shorten titles/descriptions in `_i18n` and rebuild (item 3).
4. Generate `sitemap.xml` in `build-i18n.mjs` (item 4).
5. Decide about `_template.html` and the partner block (items 5–6).
6. Run PageSpeed Insights and Search Console coverage on the live site to confirm
   items 7 and anything indexing-related.
